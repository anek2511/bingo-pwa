# BINGO • เกมบิงโก 75 ลูก

## เปิดเล่นทันที

แตกไฟล์ ZIP ให้ครบ แล้วเปิด `bingo/index.html` ในเบราว์เซอร์บนคอมพิวเตอร์ ไฟล์ HTML, CSS, JavaScript และไอคอนต้องอยู่ในโฟลเดอร์เดียวกัน สามารถเล่นทั้งสองโหมดได้โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม การบันทึกเมื่อเปิดไฟล์โดยตรงขึ้นอยู่กับเบราว์เซอร์

## วิธีเล่น

- **ผู้เล่น** แตะเลขที่ประกาศเพื่อทำเครื่องหมาย แตะซ้ำเพื่อยกเลิก ช่อง FREE ตรงกลางนับให้อัตโนมัติ เมื่อครบ 5 ช่องในแนวนอน แนวตั้ง หรือแนวทแยง จะขึ้น BINGO พร้อมไฮไลต์ช่องที่ชนะ
- **สุ่มบัตรใหม่** สุ่มเลขตามคอลัมน์ B 1–15, I 16–30, N 31–45, G 46–60, O 61–75 และเริ่มทำเครื่องหมายใหม่ กด **ล้างเครื่องหมาย** เพื่อใช้บัตรเดิมอีกรอบ
- **ผู้ดำเนินเกม** ใช้เครื่องหนึ่งเครื่องสุ่มและประกาศให้ผู้เล่นทราบ ประวัติเรียงจากล่าสุด กด **เริ่มรอบใหม่** เพื่อล้างประวัติแล้วเริ่มสุ่มใหม่
- เปิด **อ่านเลขอัตโนมัติ** หรือกด **อ่านเลขล่าสุด** ได้เมื่อเบราว์เซอร์และอุปกรณ์มีเสียงสังเคราะห์ภาษาไทย
- บัตร เครื่องหมาย ประวัติการสุ่ม และการตั้งค่าเก็บในเบราว์เซอร์ของแต่ละเครื่อง เลขที่ผู้ดำเนินเกมสุ่มใช้การประกาศให้ผู้เล่นแตะเอง

## เปิดบนมือถือและติดตั้งบนหน้าจอหลัก

1. นำไฟล์ทั้งหมดในโฟลเดอร์ `bingo` ขึ้นเว็บโฮสต์ที่เปิดผ่าน HTTPS แล้วเปิดลิงก์ด้วยมือถือหรือ iPad
2. **iPhone / iPad** เปิดใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม → เปิดเป็นเว็บแอป (ถ้ามี) → เพิ่ม
3. **Android** เปิดใน Chrome → เมนู ⋮ → ติดตั้งและสร้างทางลัด หรือ เพิ่มลงในหน้าจอหลัก → ติดตั้ง
4. เปิดแอปขณะออนไลน์ครั้งแรกเพื่อให้เบราว์เซอร์เก็บไฟล์ จากนั้นเปิดเล่นออฟไลน์ได้ เสียงอ่านออฟไลน์ขึ้นอยู่กับเสียงที่อุปกรณ์มี

คู่มือการติดตั้ง [Apple สำหรับ iPhone](https://support.apple.com/en-gb/guide/iphone/iphea86e5236/27/ios/27) · [Apple สำหรับ iPad](https://support.apple.com/en-gb/guide/ipad/ipad8f1f7a29/27/ipados/27) · [Google สำหรับ Android](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=en)

## ทดสอบจากเครื่องพัฒนา

เมื่อมี Python 3 ให้เปิด Terminal ในโฟลเดอร์ `bingo` แล้วรัน `python3 -m http.server 8765 --bind 127.0.0.1` จากนั้นเปิด http://127.0.0.1:8765/ บนเครื่องเดียวกัน เบราว์เซอร์รองรับการทดสอบ Service Worker ผ่าน localhost
